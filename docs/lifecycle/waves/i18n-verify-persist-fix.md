## Slice outcome

All four listed checks Pass. The S9 residual (tap Deutsch, kill, next launch looks like a returning user) is closed in source: detector cache stays off until Continue or a pre-init snapshot, and preview explicitly restores the snapshot.

Open residual (not a fail here): if a preview `changeLanguage('de')` is still in flight after Continue arms `caches` for a later selection, that late callback can write `i18nextLng` to the stale id. `previewSeq` only skips `restore`, not the detector write. Kill-before-Continue is unaffected because caches stay `[]`. `i18n.init().then` restore on a new profile could also wipe a same-session Continue write if init finished after Continue; `languageCompleted` would still skip the picker.
