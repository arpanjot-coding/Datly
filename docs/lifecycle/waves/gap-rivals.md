## Rival notes

### Tableau Desktop

**What it is.** Windows/Mac desktop BI authoring app, with a matching web-authoring workspace on Tableau Cloud/Server. Daily work is connect, shape on the Data Source page, then drag fields onto shelves to build worksheets, dashboards, and stories.

**Core capabilities (docs)**

- Workspace: menus, toolbar, Data pane, Analytics pane, cards/shelves (Columns, Rows, Marks, Filters, Pages, Legends), view canvas, status bar, sheet tabs. Side bar can collapse. Presentation mode hides everything except the view (Desktop only). Show Me recommends chart types. ([workspace](https://help.tableau.com/current/pro/desktop/en-us/environment_workspace.htm))
- Data pane: connections, dimensions above the gray line, measures below, calculated fields, sets, parameters (global to the workbook). Search fields. View Data icon for underlying rows. Hierarchies, rename, default properties. ([data pane](https://help.tableau.com/current/pro/desktop/en-us/datafields_understanddatawindow.htm))
- Data Source page: left pane of tables/files, logical canvas (relationships), physical canvas (joins/unions), data grid (first 1,000 rows), metadata grid (fields as rows: rename, hide, type). Refresh control on extracts. ([data source page](https://help.tableau.com/current/pro/desktop/en-us/environment_datasource_page.htm))
- Joins: inner/left/right/full outer, multi-clause, calculations in clauses where the source allows, unions, cross-database joins, plus **relationships** as the default combine method. ([joins](https://help.tableau.com/current/pro/desktop/en-us/joining_tables.htm))
- Data Interpreter: detects titles, notes, stacked headers, empty cells; finds sub-tables in Excel, CSV, PDF, Google Sheets. Does not mutate source files. ([Data Interpreter](https://help.tableau.com/current/pro/desktop/en-us/data_interpreter.htm))
- Calculated fields: Analysis > Create Calculated Field; used like any other field. ([calculations](https://help.tableau.com/current/pro/desktop/en-us/calculations_calculatedfields_create.htm))
- Parameters: placeholders in formulas, filters, and views; Show Parameter Control. ([parameters](https://help.tableau.com/current/pro/desktop/en-us/changing-views-using-parameters.htm))
- Filters: drag fields to Filters shelf; dimension, measure, and date filter dialogs. ([filters](https://help.tableau.com/current/pro/desktop/en-us/filtering.htm))
- Undo/redo: unlimited within a session, not persisted across sessions. Toolbar buttons plus Ctrl/Cmd+Z. ([undo](https://help.tableau.com/current/pro/desktop/en-us/inspectdata_undo.htm))
- Bookmarks: Window > Bookmark > Create Bookmark saves a single worksheet as `.tbm`; open from any workbook. Distinct from Power BI "bookmarks" (saved viz state). ([save](https://help.tableau.com/current/pro/desktop/en-us/save_savework.htm))
- Export/share: Desktop publishes to Server/Cloud; web Download image/data/crosstab/PDF. Pause Auto Updates / Run Update for query control. ([workspace toolbar](https://help.tableau.com/current/pro/desktop/en-us/environment_workspace.htm))

**Daily flow.** Connect on Start page -> Data Source page (relationships/joins, Interpreter, types, aliases) -> worksheet (drag to shelves, Show Me, filters, parameters, calcs) -> dashboard/story -> publish. Pause updates while iterating, then Run Update.

**Differentiators.** Viz-first shelves and marks card; relationships vs joins; Data Interpreter for messy spreadsheets; unlimited in-session undo; Desktop-only presentation mode and Start-page connect chrome.

**Desktop-specific chrome.** Tableau icon to Start page; Window > Show Toolbar / Show Status Bar; Presentation Mode; Pause Auto Updates and Run Update; native Windows/Mac install; cube sources on Windows only.

**2025-2026 AI (not P0 chrome).** Tableau Agent in viz authoring on Desktop 2025.1+ when signed into a Cloud/Server site with AI turned on: explore data, create visualizations, build/explain calculated fields. Tableau Agent in Pulse; Dashboard Narratives / Dashboard Q&A (beta, 2026.x). Tableau Next is a separate Salesforce-hosted agentic product. ([AI in Tableau](https://help.tableau.com/current/tableau/en-us/tableau_gai_solutions.htm), [Tableau Agent](https://help.tableau.com/current/online/en-us/web_author_einstein.htm))

**Sources.** URLs above. tableau.com/products/desktop and all-features were Access Denied here.

### Power BI Desktop

**What it is.** Free **Windows** report-authoring app. Connect, Power Query transform, model (relationships + DAX), design visuals, then publish to the Power BI service. Mobile is view-only.

**Core capabilities (docs)**

- Three main views plus Power Query Editor: **Report**, **Table**, **Model**, opened from left icons. ([query overview](https://learn.microsoft.com/en-us/power-bi/transform-model/desktop-query-overview))
- Report: ribbon (Home, Insert, Modeling), report canvas, Fields pane, Visualizations pane. 30+ built-in visuals, AppSource custom visuals. ([getting started](https://learn.microsoft.com/en-us/power-bi/fundamentals/desktop-getting-started), [overview](https://learn.microsoft.com/en-us/power-bi/fundamentals/power-bi-overview))
- Power Query Editor: ribbon (Home, Transform, Add Column, View), Queries pane, center data grid, Query Settings with **Applied Steps**. Advanced Editor for M. Close & Apply loads the model. 100+ connectors. ([query overview](https://learn.microsoft.com/en-us/power-bi/transform-model/desktop-query-overview))
- Profiling in Power Query: column quality (valid/error/empty), column distribution, column profile (stats + value distribution). Default first 1,000 rows, option for entire dataset. Quick-clean actions from the profile UI. ([profiling](https://learn.microsoft.com/en-us/power-query/data-profiling-tools))
- Model: relationships in Model view; DAX calculated columns, measures, visual calculations (GA in 2026 updates). Field parameters (GA). DAX user-defined functions GA June 2026.
- DAX query view: fourth left-nav view. Query editor with IntelliSense, format, comment, find/replace, command palette, results grid with sort/filter (GA), query tabs saved in `.pbix` / `.dax` files, Data pane quick queries (top 100 rows, column stats, define measures). Copilot can generate DAX queries. ([DAX query view](https://learn.microsoft.com/en-us/power-bi/transform-model/dax-query-view))
- Bookmarks: save report page state (filters, slicers, visibility) for storytelling and navigators. ([bookmarks](https://learn.microsoft.com/en-us/power-bi/create-reports/desktop-bookmarks), [navigators](https://learn.microsoft.com/en-us/power-bi/create-reports/button-navigators))
- Refresh: Desktop Refresh; service scheduled refresh, DirectQuery, Direct Lake framing. Performance Analyzer captures visual DAX and can send it to DAX query view.
- Q&A and Smart Narratives (classic NL). Export/publish to service; Analyze in Excel.

**Daily flow.** Get Data -> Transform Data (shape, types, joins/merges, profile) -> Close & Apply -> Model (relationships, measures) -> Report (visuals, slicers, bookmarks) -> Publish. Optional DAX query view to test measures without a visual.

**Differentiators.** Power Query applied-steps replay; semantic model + DAX as the calculation layer; Windows-only Desktop; Fabric OneLake / Direct Lake; Copilot deeply wired into report, model, and DAX query view.

**Desktop-specific chrome.** Windows installer (Store or Download Center); left view switcher; ribbon; Performance Analyzer; External Tools; composite models. No Mac native Desktop.

**2025-2026 AI.** Copilot in Desktop and service: chat with report, generate/edit report pages, DAX generation, measure descriptions (`///`), Copilot in web modeling (preview June 2026), standalone Copilot, Copilot in apps. Requires paid Fabric/Premium capacity. ([Copilot overview](https://learn.microsoft.com/en-us/power-bi/create-reports/copilot-introduction), [what's new](https://learn.microsoft.com/en-us/power-bi/fundamentals/whats-new), [archive](https://learn.microsoft.com/en-us/power-bi/fundamentals/desktop-latest-update-archive))

**Sources.** Microsoft Learn URLs above.

### Positron / RStudio / JupyterLab

These are the code-first data-science IDEs. They share a pane-and-session model more than a BI canvas.

#### Positron

**What it is.** Free, source-available (Elastic License 2.0) VS Code fork from Posit for Python and R. Desktop on macOS, Windows, Linux. Positron Pro runs the same UI in the browser via Posit Workbench.

**Core capabilities (product + blog)**

- Layout: Activity Bar, Primary Side Bar (Explorer), Editor, Panel (Console, Terminal), Secondary Side Bar (Variables, Plots, Help, Connections). ([tour](https://posit.co/blog/a-quick-tour-of-positron), [features](https://positron.posit.co/features.html))
- Native Jupyter notebook editor (not a bolted-on extension). ([notebook editor](https://positron.posit.co/positron-notebook-editor.html), [product](https://posit.co/products/ide/positron))
- Data Explorer: spreadsheet-style grid, filter/sort, column summary statistics; open CSV/Parquet before load; Variables pane "spreadsheet" icon; Python `%view`, R `View()`. Three areas: data grid, summary panel, filter bar. ([tour](https://posit.co/blog/a-quick-tour-of-positron), [EDA](https://posit.co/blog/eda-in-positron))
- Interpreter picker: multiple R/Python sessions in one workspace. Connections pane for DB schema + table preview. Plots pane. Help pane (`F1`, `?`, `help()`). Git. Open VSX extensions. Quarto, Shiny/data-app preview, publish to Posit Connect.
- Keyboard/editor: VS Code keybindings, command palette, remote SSH.

**Daily flow.** Open project -> pick interpreter -> script or notebook -> inspect frames in Data Explorer -> iterate in Console -> plot pane -> optional publish.

**Differentiators vs RStudio.** VS Code extension ecosystem + polyglot R/Python; richer Data Explorer (column summaries, file-open-before-load). vs JupyterLab: dedicated Variables/Plots/Connections panes without assembling extensions.

**Desktop chrome.** Native window chrome, activity bar, interpreter picker in the title area, dedicated data/plot/console panes. Workbench variant adds SSO, managed credentials, admin-enforced AI providers.

**2025-2026 AI.** Positron Assistant (preview): LLM in-IDE with Console, Variables, and Plots context; attach files. Posit Assistant later connected to Databricks-hosted models (Aug 2026 blog). MCP servers on Posit Connect (Jul 2026). ([tour](https://posit.co/blog/a-quick-tour-of-positron), [Databricks models](https://posit.co/blog/posit-assistant-now-connects-your-databricks-hosted-models-preview))

#### RStudio

**What it is.** Posit's long-standing desktop/server IDE, still shipped alongside Positron. Four-pane layout is the category template many data IDEs copy.

**Core capabilities (user guide)**

- Panes: Source; Console; Environment pane (Environment, History, Connections, Build, VCS, Tutorial); Files / Plots / Packages / Help / Viewer. ([pane layout](https://docs.posit.co/ide/user/ide/guide/ui/ui-panes.html))
- Environment: objects in the session. History: executed commands, searchable, saveable as `.Rhistory`.
- Data viewer via `View()` (spreadsheet of a data frame). Connections tab. Keyboard shortcuts throughout.

**Daily flow.** Script in Source -> send to Console -> inspect Environment -> View() frames -> Plots/Help.

**Desktop chrome.** Classic 2x2 pane grid, customizable; Desktop and Workbench/Server.

#### JupyterLab

**What it is.** Extensible notebook IDE (browser, often local via `jupyter lab`). 4.6.0 documented Jul 2026.

**Core capabilities**

- Main work area (tabs of notebooks, editors, terminals, consoles), collapsible left/right sidebars, menu bar, workspaces that persist layout. File browser, running kernels, TOC, extension manager, debugger, property inspector. Command palette. Customizable keyboard shortcuts; vim/emacs/Sublime maps for the text editor. CSV/JSON/Markdown/Vega viewers. Simple Interface mode. ([interface](https://jupyterlab.readthedocs.io/en/latest/user/interface.html))
- Debugger: breakpoints, variables tree/table, call stack, kernel sources (when kernel supports debug protocol). ([debugger](https://jupyterlab.readthedocs.io/en/latest/user/debugger.html))
- 4.6: file browser Date Created, editable breadcrumbs, CSV viewer uses widest row as column count, recently edited jump, debugger/file-browser polish. ([4.6 blog](https://blog.jupyter.org/jupyterlab-4-6-and-notebook-7-6-are-out-dd84e1e919f2))

**Daily flow.** File browser -> notebook -> kernel -> cells -> outputs in-place; optional CSV viewer; debugger sidebar.

**Gap vs Positron/RStudio (from their own docs, not Datly).** No first-party Data Explorer equivalent in core JupyterLab; variable inspector is debugger- or extension-based. Collaboration is not built-in (needs JupyterHub/Realtime extensions).

**Sources.** URLs in this section.

### Hex

**What it is.** Hosted collaborative analytics notebook (web). SQL, Python, R, no-code cells, charts, and a published app builder. Not a desktop install.

**Core capabilities (product + docs)**

- Cell types: SQL (Jinja, dbt, schema browser, typeahead, syntax highlighting), Python/R with package management, Table, Pivot, Filter, Chart, Map, Table Display, Single Value, Input parameters, Markdown. ([notebooks](https://hex.tech/product/notebooks/), [SQL cells](https://learn.hex.tech/docs/explore-data/cells/sql-cells/sql-cells-introduction), [calculations](https://learn.hex.tech/docs/explore-data/cells/calculations))
- SQL IDE-in-a-cell: warehouse or DuckDB-on-dataframes; chained SQL (upstream query inlined as CTE); query mode (1k-row preview, pushdown) vs dataframe mode (full Pandas); `⌘/Ctrl+Enter`; compiled SQL view; query caching; cancel; multi-statement where the warehouse allows; metadata comments injected for warehouse audit.
- Spreadsheet-style **Calculations** language (Text/Number/Boolean/Datetime, If/Switch, aggregates) on Table Display / Explore. Parameterized via Jinja. No window functions; column-level only.
- Graph-based reactive execution; Auto vs Cell-only run. Explore cell for visual exploration of SQL/Python/Pivot output (added as a cell type, 2024 press).
- Collaboration: comments, sharing, published apps with layout (rows/columns/tabs), scheduled runs (implied by product; not fully re-read here).

**Daily flow.** Pick connection -> SQL cell -> inspect table -> chart/pivot/calc or Python -> parameterize -> publish app.

**Differentiators.** Warehouse pushdown query mode; first-class SQL+Python in one DAG; no-code cells that compile back to SQL; notebook agent with confirm/undo of cell edits.

**Desktop chrome.** None. Browser workspace. Hex CLI exists as a platform product.

**2025-2026 AI.** Notebook agent: natural language, warehouse/semantic-model context, mention cells/tables/projects, generate/edit/move/delete cells (SQL, Python, Markdown, Pivot, Inputs, charts), subagents, web search, fix-with-agent vs quick fix, app layout, model/effort picker, pending-change Confirm/Undo. Formerly branded Magic. ([notebook agent](https://learn.hex.tech/docs/explore-data/notebook-view/notebook-agent))

**Sources.** URLs above.

### DataGrip and DBeaver

SQL IDEs. Daily work is connect, browse schema, write SQL, inspect/edit result grids, export.

#### DataGrip

**Core capabilities**

- Multi-database IDE (50+ engines listed on the product page). Database explorer, query console, code completion aware of tables/FKs/objects in the current script, inspections and quick-fixes, refactoring. ([product](https://www.jetbrains.com/datagrip/), [features overview](https://lp.jetbrains.com/features-overview/))
- Query history log; parameterized SQL; local history; VCS (Git, SVN, Mercurial). Custom keymap, themes.
- Data editor: Excel-like grid, filter/search (Cmd+F client-side, regex), aggregations (count/sum/avg/min/max, custom), charts, geo map viewer, in-place edit with preview/commit/revert, related-rows via FKs, side-by-side diff of result sets/tables, export CSV/JSON/HTML/Markdown/Excel/custom, copy to another database. ([working with data](https://lp.jetbrains.com/working-with-data/))
- Files: SQL/CSV/JSON alongside databases. Import delimiter files.

**Daily flow.** Data source -> schema tree -> console or file -> execute -> grid + aggregations -> optional edit/export. History to recall statements.

**Differentiators.** JetBrains inspections/refactoring; result-set diff; AI agents via ACP (Claude Agent, Codex, Copilot, Cursor).

**Desktop chrome.** Cross-platform JVM desktop; tool windows; keymap; appearance. Also embedded as Database plugin in other JetBrains IDEs.

**2025-2026 AI.** JetBrains AI: schema-aware NL-to-SQL, fix, dialect convert; multi-agent (Claude Agent, Codex); GitHub Copilot and Cursor via ACP; local models. ([AI](https://www.jetbrains.com/datagrip/features/ai/))

#### DBeaver

**Core capabilities**

- Universal DB tool. Editions: Community, Lite, Enterprise, Ultimate (cloud). Spreadsheet-like data manipulation, SQL editor, ER diagrams, admin, migration, session monitoring. ([docs home](https://dbeaver.com/docs/dbeaver/))
- Window: menu bar, toolbar, shortcut bars, dockable editors/views, status bar. Customize Perspective. ([window](https://dbeaver.com/docs/dbeaver/Application-Window-Overview/))
- SQL Editor: scripts bound to a connection, spelling, hyperlinks to objects, dialect highlighting, templates, auto-complete, formatting, variables, execution plan, visual query builder, outline (Alt+Shift+Q, O), error gutter, execute selected, multiple results in one tab, layout toggle (Ctrl+6). Active catalog/schema switch (Ctrl+0 / Ctrl+9). ([SQL Editor](https://dbeaver.com/docs/dbeaver/SQL-Editor/))
- Data Editor: grid/text/spatial/chart/record/JSON/XML views; filter field and custom filters; history navigation; Calc panel (SUM/MAX/AVG); Grouping; Metadata; References; Value viewer; fetch size; add/dup/delete rows; export; generate SQL; virtual keys; bookmarks (Edit menu: Add Bookmark). ([Data Editor](https://dbeaver.com/docs/dbeaver/Data-Editor/))
- Schema compare, data transfer, search across objects.

**Daily flow.** Database Navigator -> table Data tab or SQL script -> filter/sort grid -> optional charts/calc -> save edits or export.

**Differentiators.** Visual query builder; GIS; mock data; cheap/free Community; very wide driver set.

**Desktop chrome.** Eclipse-style perspectives, dockable views, toolbar customization. Native-feeling desktop on Win/Mac/Linux.

**2025-2026 AI.** AI Assistant (providers: OpenAI, GitHub Copilot, Azure OpenAI, Gemini, Ollama, Claude, Bedrock): chat, NL `@ai` command, query suggestion, explain query/plan, fix errors, describe objects, AI tools/MCP, map columns on data transfer. Several features PRO-only. ([AI](https://dbeaver.com/docs/dbeaver/AI-Smart-Assistance/))

### Databricks notebooks / SQL editor

**What it is.** Web workspace on the lakehouse. Notebooks (Python, SQL, Scala, R) plus a dedicated SQL editor. Not a local desktop IDE.

**Notebooks** ([docs](https://docs.databricks.com/aws/en/notebooks/))

- Real-time coauthoring, automatic versioning, built-in viz, cell types, keyboard shortcuts, IntelliSense, comments, import/export, dashboards from notebook results, widgets (parameters), debugger, unit testing.
- Results tables: filter, download. Compute attached to the notebook.

**New SQL editor** ([docs](https://docs.databricks.com/aws/en/sql/user/sql-editor/), [results](https://docs.databricks.com/aws/en/sql/user/sql-editor/results); default on late May 2026, legacy retired late July 2026)

- Workspace file browser in the editor, catalog/schema selectors, collapse code, command palette, code comments, version history.
- Named parameters / parameter widgets (query-based dropdowns not supported in the new editor).
- Custom SQL format, keyboard shortcuts.
- Results: multiple statement tabs, viz editor, add viz to AI/BI dashboard, download CSV/TSV/Excel up to ~5GB, copy, post-query filters (equal/one-of/contains/starts with/between/null/comparisons/OR; NL filter via Genie Code). Shared results, 64,000-row collaborator cap.
- Real-time co-edit of queries. Run selected/multi-statement.

**Daily flow.** Catalog pick -> SQL or notebook cell -> run on warehouse/cluster -> grid + viz + filter -> dashboard or download. Widgets parameterize notebooks.

## Category capability checklist

How to read **Defining vs optional**:

- **Defining**: professionals expect this chrome in *this category* (data IDE / analytics workbench / BI desktop / SQL IDE). Absence is a product gap, not a taste difference. A capability can be defining for BI desktops but optional for SQL IDEs (example: bookmarks-as-viz-state).
- **Optional**: valuable, but not table-stakes across the whole category, or only recently common (agents, MCP), or naming-specific.

"Who has it" lists **documented** owners from this research. Blank / not listed means not verified here, not "they lack it."

| Capability | Who has it (documented) | Defining or optional | Notes |
