01 / จากคำถามสู่ความเข้าใจ

ตามความอยากรู้ของคุณ
เก็บบริบทไว้ครบ

จากตารางสู่ข้อค้นพบที่มีประโยชน์ในพื้นที่เดียว ตั้งคำถาม ปรับแต่ง และตรวจสอบไปพร้อมกับการวิเคราะห์

01

นำข้อมูลของคุณมาใช้

โหลดไฟล์ในเครื่อง เชื่อมต่อฐานข้อมูลที่รองรับ หรือสำรวจตัวอย่างที่มีให้

02

ตั้งคำถามถัดไป

อธิบายสิ่งที่ต้องการสำรวจ ปรับแผนภูมิด้วยตัวควบคุมการเข้ารหัสภาพ หรือถามคำถามต่อเนื่อง

03

ตรวจสอบ แล้วอธิบาย

ตรวจสอบแถวข้อมูลที่แปลงแล้ว ส่งออก CSV และเพิ่มบริบทให้ข้อค้นพบในรายงานที่แก้ไขได้

02 / มองให้ใกล้ขึ้น

เห็นกระบวนการ
ไม่ใช่เพียงคำตอบ

มุมมองจากแอปจริงที่เปิดให้ดูใกล้ขึ้น สำรวจฟีเจอร์ที่ช่วยให้ติดตามการวิเคราะห์ได้ง่ายขึ้น

↳

แถวข้อมูลเบื้องหลัง
เส้นแผนภูมิ

แผนภูมิคือจุดเริ่มต้น เปิดตารางเบื้องหลังเพื่อตรวจสอบค่า ทบทวนการแปลงข้อมูล และพิจารณาว่าผลลัพธ์หมายความว่าอย่างไร

  • แผนภูมิและตารางผลคำนวณอยู่ด้วยกัน
  • ตรวจสอบและส่งออกแถวข้อมูลที่แปลงแล้ว
  • ทบทวนผลลัพธ์ก่อนแชร์

ภาพจากแอปจริง จัดกรอบใหม่เพื่อให้ชัดเจน ข้อมูลใช้ประกอบตัวอย่างเท่านั้น การวิเคราะห์ที่สร้างโดย AI ต้องได้รับการทบทวน

03 / ติดตามได้ทุกขั้น

AI ช่วยคุณสำรวจ
คุณเป็นผู้ตัดสินใจ

การวิเคราะห์ที่ดีต้องมีมากกว่าแผนภูมิที่ดูน่าเชื่อถือ Datly เปิดให้คุณตรวจสอบงานระหว่างขั้นตอนได้

ติดตามคำถาม

รักษาความต่อเนื่อง
ของแนวคิด

เธรดข้อมูลจัดระเบียบคำถาม การแปลงข้อมูล ตารางที่ได้มา และแผนภูมิ ติดตามการสำรวจขณะที่งานดำเนินไป

สำรวจเธรดข้อมูล ↗
ปรับมุมมอง

แผนภูมิที่คุณ
นำไปทำงานต่อได้

ใช้ตัวควบคุมการเข้ารหัสภาพสำหรับแกน สี และคุณสมบัติอื่นของแผนภูมิ ปรับมุมมองเมื่อคำถามของคุณชัดเจนขึ้น

สำรวจพื้นที่แผนภูมิ ↗
อธิบายข้อค้นพบ

มากกว่า

ผสานคำอธิบายกับภาพแผนภูมิในรายงานที่แก้ไขได้ บันทึกเป็นภาพ หรือใช้การพิมพ์ของเบราว์เซอร์เพื่อสร้าง PDF

สำรวจรายงาน ↗

04 / เริ่มจากสิ่งที่คุณมี

ข้อมูลของคุณ
จุดเริ่มต้นที่คุ้นเคย

ทำงานกับไฟล์และแหล่งข้อมูลที่รองรับ การเชื่อมต่อขึ้นอยู่กับไดรเวอร์ ข้อมูลรับรอง และการเข้าถึงเครือข่ายที่เหมาะสม

วันนี้เริ่มจากไฟล์
พรุ่งนี้อาจเป็นคลังข้อมูล

เริ่มต้นง่าย ๆ ด้วย CSV หรือชุดข้อมูลตัวอย่าง เพิ่มการเชื่อมต่อที่รองรับเมื่อคำถามต้องใช้ข้อมูลมากขึ้น

ดูการพัฒนาตัวเชื่อมต่อ ↗
  • Pg
    PostgreSQLฐานข้อมูลเชิงสัมพันธ์
  • Db
    Databricksคลังข้อมูล SQL
  • Bq
    BigQueryคลังข้อมูลบนคลาวด์
  • Ch
    ClickHouseฐานข้อมูลเชิงวิเคราะห์
  • My
    MySQLฐานข้อมูลเชิงสัมพันธ์
  • Ms
    SQL Serverฐานข้อมูลเชิงสัมพันธ์
  • S3
    Amazon S3ที่จัดเก็บออบเจ็กต์
  • Az
    Azure Blobที่จัดเก็บออบเจ็กต์
  • At
    Athenaคิวรีแบบไร้เซิร์ฟเวอร์
  • Mo
    MongoDBฐานข้อมูลเอกสาร
  • Co
    Cosmos DBฐานข้อมูลเอกสาร
  • Ku

  • Su

  • ↥

  • Wb

  • Ex

แสดงตัวเลือกแหล่งข้อมูลทั้ง 16 รายการ ชื่อบอกถึงส่วนที่มีการพัฒนาไว้ ไม่ใช่การผสานรวมที่ได้รับการรับรอง

05 / เลือกอย่างเข้าใจ

ประมวลผลในเครื่อง
ขอบเขตข้อมูลชัดเจน

อ่านโค้ดบริบทของโมเดล ↗
01 / การประมวลผล

ทำงานในสภาพแวดล้อมของคุณ

DuckDB และ Python ทำการแปลงข้อมูลในสภาพแวดล้อมที่โฮสต์ Datly รวมถึงการติดตั้งในเครื่องคอมพิวเตอร์ของคุณ

02 / บริบทของโมเดล

รู้ว่า AI ได้รับอะไร

คำขอ AI อาจมีสคีมา ค่าตัวอย่างและแถวตัวอย่าง พรอมป์ต์ และผลลัพธ์จากเครื่องมือ ผู้ให้บริการโมเดลคลาวด์จะได้รับบริบทที่ส่งไป

03 / การตั้งค่าของคุณ

เลือกโมเดลของคุณ

เชื่อมต่อผู้ให้บริการที่รองรับ หรือตั้งค่าโมเดลในเครื่องผ่าน Ollama คำขอ AI แบบในเครื่องต้องใช้ปลายทางในเครื่อง ส่วนแหล่งข้อมูลระยะไกลยังต้องเข้าถึงเครือข่าย

06 / คำถามดี ๆ ข้อต่อไป

ตั้งค่าอีกนิด
มีอะไรให้สำรวจอีกมาก

บิลด์จากซอร์สโค้ดแล้วเปิด Datly ในเบราว์เซอร์ เริ่มจากชุดข้อมูลตัวอย่าง แล้วตั้งค่าโมเดลสำหรับการสำรวจที่มี AI ช่วย

  • Python 3.11 ขึ้นไป
  • Node.js และ Yarn สำหรับส่วนหน้า
  • uv สำหรับสภาพแวดล้อม Python

มีคำถามหรือข้อเสนอแนะ? ↗
Datly คืออะไร?+

Datly คือพื้นที่วิเคราะห์ข้อมูลโอเพนซอร์สที่สร้างบน Data Formulator ของ Microsoft Research ผสานการสำรวจด้วยภาษาธรรมชาติ ตัวควบคุมแผนภูมิแบบภาพ เธรดข้อมูล การตรวจสอบตาราง และรายงานที่แก้ไขได้ โครงการอยู่ในระยะเบตา

ข้อมูลของฉันจะอยู่ในคอมพิวเตอร์หรือไม่?+

การติดตั้งในเครื่องทำการแปลงข้อมูลบนคอมพิวเตอร์ของคุณ คำขอ AI อาจมีแถวตัวอย่าง ค่าฟิลด์ พรอมป์ต์ และผลลัพธ์เครื่องมือที่ส่งไปยังโมเดลที่ตั้งค่าไว้ หากเลือกผู้ให้บริการคลาวด์ ผู้ให้บริการนั้นจะได้รับบริบทนี้ ปลายทางโมเดลในเครื่องช่วยให้คำขอโมเดลอยู่ในเครื่องได้ โปรดตรวจสอบการตั้งค่าและแหล่งข้อมูลที่เชื่อมต่อ

การตรวจสอบตารางรับประกันคำตอบที่ถูกต้องหรือไม่?+

ไม่ ตารางช่วยให้ตรวจสอบค่าที่คำนวณได้ แต่ AI ยังอาจเลือกการแปลง การสรุปรวม หรือการตีความที่ไม่ถูกต้อง ทบทวนงานที่สร้างขึ้น ข้อมูลเบื้องหลัง และสมมติฐานทางธุรกิจก่อนนำผลลัพธ์ไปใช้

ฉันใช้โมเดลใดได้บ้าง?+

โค้ดรองรับ OpenAI, Azure OpenAI, Anthropic, Gemini และปลายทาง Ollama ในเครื่อง คุณตั้งค่าผู้ให้บริการและข้อมูลรับรองเอง ความพร้อมของโมเดล ความสามารถ และค่าใช้งานขึ้นอยู่กับผู้ให้บริการ

ฉันสร้างรายงานและแดชบอร์ดได้หรือไม่?+

คุณแก้ไขรายงานข้อความแบบจัดรูปแบบพร้อมภาพแผนภูมิ ส่งออกรายงานเป็นภาพ หรือพิมพ์เป็น PDF ได้ แดชบอร์ดปัจจุบันบันทึกการอ้างอิงแผนภูมิและแสดงตัวแทนชื่อ/ประเภทเท่านั้น ยังไม่มีการพัฒนาแดชบอร์ดหลายแผนภูมิที่แสดงผลและโต้ตอบได้

Datly ใช้ฟรีหรือไม่?+

ซอร์สโค้ด Datly เปิดให้ใช้ภายใต้สัญญาอนุญาต MIT ผู้ให้บริการโมเดล โครงสร้างพื้นฐานที่เชื่อมต่อ หรือบริการโฮสต์อาจมีค่าใช้จ่ายของตนเอง ดูคู่มือการตั้งค่าและรุ่นที่เผยแพร่ในคลังโค้ดสำหรับตัวเลือกการติดตั้งปัจจุบัน
