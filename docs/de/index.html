Fragen oder Feedback? ↗
Was ist Datly?+

Datly ist ein Open-Source-Arbeitsbereich für Datenanalyse auf Basis von Data Formulator von Microsoft Research. Er vereint Erkundung in natürlicher Sprache, visuelle Diagrammsteuerung, Analysepfade, Tabellenprüfung und bearbeitbare Berichte. Das Projekt befindet sich in der Betaphase.

Bleiben meine Daten auf meinem Computer?+

Eine lokale Installation führt Transformationen auf Ihrem Computer aus. KI-Anfragen können Beispielzeilen, Feldwerte, Prompts und Werkzeugausgaben enthalten, die an das konfigurierte Modell gesendet werden. Wenn Sie einen Cloud-Anbieter wählen, erhält dieser den Kontext. Ein lokaler Modellendpunkt kann Modellanfragen lokal halten; prüfen Sie Ihre Konfiguration und die verbundenen Datenquellen.

Garantiert die Tabellenprüfung eine korrekte Antwort?+

Nein. Die Tabelle hilft Ihnen beim Prüfen der berechneten Werte, doch die KI kann weiterhin eine falsche Transformation, Aggregation oder Interpretation wählen. Prüfen Sie die erzeugte Arbeit, die zugrunde liegenden Daten und die fachlichen Annahmen, bevor Sie sich auf ein Ergebnis verlassen.

Welche Modelle kann ich verwenden?+

Der Code unterstützt OpenAI, Azure OpenAI, Anthropic, Gemini und lokale Ollama-Endpunkte. Sie konfigurieren Ihren Anbieter und Ihre Zugangsdaten. Verfügbarkeit, Fähigkeiten und mögliche Nutzungskosten der Modelle hängen vom jeweiligen Anbieter ab.

Kann ich Berichte und Dashboards erstellen?+

Sie können Rich-Text-Berichte mit Diagrammbildern bearbeiten, ein Berichtsbild exportieren oder als PDF drucken. Die aktuelle Dashboard-Implementierung speichert Diagrammreferenzen und zeigt Platzhalter für Titel und Typ an; ein gerendertes, interaktives Dashboard mit mehreren Diagrammen ist noch nicht implementiert.

Ist Datly kostenlos?+

Der Quellcode von Datly steht unter der MIT-Lizenz zur Verfügung. Für Ihren Modellanbieter, verbundene Infrastruktur oder Hosting können eigene Kosten anfallen. Aktuelle Installationsmöglichkeiten finden Sie in den Anleitungen und Releases des Repositorys.
