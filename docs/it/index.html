Domande o commenti? ↗
Che cos’è Datly?+

Datly è uno spazio di analisi open source basato su Data Formulator di Microsoft Research. Unisce esplorazione in linguaggio naturale, controlli visivi dei grafici, percorsi di analisi, ispezione delle tabelle e report modificabili. Il progetto è in fase beta.

I miei dati rimangono sul mio computer?+

Un’installazione locale esegue le trasformazioni sul tuo computer. Le richieste all’IA possono includere righe di esempio, valori dei campi, istruzioni e output degli strumenti, inviati al modello configurato. Se scegli un fornitore cloud, quel fornitore riceve il contesto. Un endpoint di modello locale può mantenere locali le richieste; verifica la configurazione e le fonti dati collegate.

L’ispezione della tabella garantisce una risposta corretta?+

No. La tabella aiuta a esaminare i valori calcolati, ma l’IA può comunque scegliere una trasformazione, un’aggregazione o un’interpretazione errata. Controlla il lavoro generato, i dati sottostanti e le ipotesi di business prima di fare affidamento su un risultato.

Quali modelli posso usare?+

Il codice supporta OpenAI, Azure OpenAI, Anthropic, Gemini ed endpoint locali di Ollama. Configuri tu il fornitore e le credenziali. La disponibilità, le capacità e gli eventuali costi d’uso dei modelli dipendono dal fornitore.

Posso creare report e dashboard?+

Puoi modificare report in testo formattato con immagini dei grafici, esportare un’immagine del report o stamparlo in PDF. L’implementazione attuale delle dashboard salva riferimenti ai grafici e mostra segnaposto per titolo e tipo; una dashboard visualizzata e interattiva con più grafici non è ancora implementata.

Datly è gratuito?+

Il codice sorgente di Datly è disponibile con licenza MIT. Il fornitore del modello, l’infrastruttura collegata o l’hosting possono avere costi propri. Consulta le istruzioni e le versioni del repository per conoscere le opzioni di installazione attuali.
