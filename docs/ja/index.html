自分のワークスペースで実行

DuckDBとPythonは、Datlyをホストする環境で変換処理を実行します。自分のコンピューターへのローカルインストールも含まれます。

02 / モデルへのコンテキスト

AIに何が渡るかを知る

AIへのリクエストには、スキーマ、サンプル値やデータ行、プロンプト、ツールの出力が含まれる場合があります。クラウドモデルの提供元は、送信されたコンテキストを受け取ります。

03 / あなたの設定

モデルを選ぶ

対応する提供元に接続するか、Ollamaでローカルモデルを設定できます。AIへのリクエストをローカルに保つには、ローカルのエンドポイントが必要です。リモートのデータソースには、引き続きネットワークアクセスが必要です。

ご質問・フィードバック ↗
Datlyとは何ですか？+

Datlyは、Microsoft ResearchのData Formulatorを基盤とした、オープンソースの分析ワークスペースです。自然言語による探索、視覚的なグラフ設定、データスレッド、テーブルの確認、編集可能なレポートを備えています。現在はベータ版です。

データは自分のコンピューター内にとどまりますか？+

ローカルにインストールした場合、変換処理は自分のコンピューター上で実行されます。AIへのリクエストには、サンプル行、フィールドの値、プロンプト、ツールの出力が含まれる場合があり、設定したモデルに送信されます。クラウドの提供元を選ぶと、その提供元がコンテキストを受け取ります。ローカルモデルのエンドポイントを使うことでモデルへのリクエストをローカルに保てますが、設定や接続先のデータソースをご確認ください。

テーブルを確認すれば、答えの正しさは保証されますか？+

いいえ。テーブルは計算された値の確認に役立ちますが、AIが誤った変換、集計、解釈を選ぶ可能性はあります。結果を判断の根拠にする前に、生成された作業、元のデータ、ビジネス上の前提条件を確認してください。

どのモデルを使えますか？+

コードにはOpenAI、Azure OpenAI、Anthropic、Gemini、ローカルのOllamaエンドポイントへの対応が含まれています。提供元と認証情報は利用者が設定します。モデルの利用可否、機能、利用料金は提供元によって異なります。

レポートやダッシュボードを作成できますか？+

グラフ画像を含むリッチテキストのレポートを編集し、レポートを画像として出力するか、PDFに印刷できます。現在のダッシュボード実装はグラフへの参照を保存し、タイトルと種類のプレースホルダーを表示します。複数のグラフを描画するインタラクティブなダッシュボードは、まだ実装されていません。

Datlyは無料ですか？+

DatlyのソースコードはMITライセンスで公開されています。モデルの提供元、接続するインフラ、ホスティングには別途費用がかかる場合があります。現在のインストール方法は、リポジトリのセットアップ手順とリリースを確認してください。
