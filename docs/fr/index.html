01 / EXÉCUTION

Travaillez dans votre espace

DuckDB et Python exécutent les transformations dans l’environnement où vous hébergez Datly, y compris lors d’une installation locale sur votre ordinateur.

02 / CONTEXTE DU MODÈLE

Sachez ce que reçoit l’IA

Les requêtes à l’IA peuvent inclure le schéma, des exemples de valeurs et de lignes, les instructions et les sorties d’outils. Un fournisseur de modèle cloud reçoit le contexte qui lui est envoyé.

03 / VOTRE CONFIGURATION

Choisissez votre modèle

Connectez un fournisseur pris en charge ou configurez un modèle local via Ollama. Pour rester locales, les requêtes à l’IA nécessitent un point d’accès local ; les sources distantes exigent toujours un accès réseau.

06 / VOTRE PROCHAINE BONNE QUESTION

Un peu de configuration.
Beaucoup à explorer.

Compilez depuis les sources et lancez Datly dans votre navigateur. Commencez avec un jeu de données d’exemple, puis configurez un modèle pour explorer avec l’aide de l’IA.

  • Python 3.11 ou version ultérieure
  • Node.js et Yarn pour l’interface
  • uv pour l’environnement Python
Lire le guide d’installation ↗Voir les versions ↗
# Get the project
git clone https://github.com/arpanjot-coding/Datly.git
cd Datly

# Build the interface
yarn
yarn build

# Install Python dependencies and launch
uv sync
uv run data_formulator
Ouvrez localhost:5567 après le lancement

Des questions ou des remarques ? ↗
Qu’est-ce que Datly ?+

Datly est un espace d’analyse en open source fondé sur Data Formulator de Microsoft Research. Il réunit l’exploration en langage naturel, les réglages visuels des graphiques, les fils d’analyse, l’inspection des tableaux et les rapports modifiables. Le projet est en bêta.

Mes données restent-elles sur mon ordinateur ?+

Une installation locale exécute les transformations sur votre ordinateur. Les requêtes à l’IA peuvent inclure des exemples de lignes, des valeurs de champs, des instructions et des sorties d’outils, envoyés au modèle configuré. Si vous choisissez un fournisseur cloud, celui-ci reçoit ce contexte. Un point d’accès de modèle local peut maintenir les requêtes en local ; vérifiez votre configuration et les sources connectées.

L’inspection du tableau garantit-elle une réponse correcte ?+

Non. Le tableau vous aide à examiner les valeurs calculées, mais l’IA peut toujours choisir une transformation, une agrégation ou une interprétation incorrecte. Vérifiez le travail généré, les données sous-jacentes et les hypothèses métier avant de vous fier à un résultat.

Quels modèles puis-je utiliser ?+

Le code prend en charge OpenAI, Azure OpenAI, Anthropic, Gemini et les points d’accès Ollama locaux. Vous configurez votre fournisseur et vos identifiants. La disponibilité des modèles, leurs capacités et les éventuels frais d’utilisation dépendent du fournisseur.

Puis-je créer des rapports et des tableaux de bord ?+

Vous pouvez modifier des rapports en texte enrichi contenant des images de graphiques, exporter une image du rapport ou l’imprimer en PDF. L’implémentation actuelle des tableaux de bord enregistre les références des graphiques et affiche des espaces réservés pour le titre et le type ; le rendu d’un tableau de bord interactif à plusieurs graphiques n’est pas encore implémenté.

Datly est-il gratuit ?+

Le code source de Datly est disponible sous licence MIT. Votre fournisseur de modèle, l’infrastructure connectée ou l’hébergement peuvent entraîner des frais distincts. Consultez les instructions et les versions du dépôt pour connaître les options d’installation actuelles.
